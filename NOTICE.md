# Third-party data and licenses

Most of this repository is the app itself: `index.html`, `style.css`, `script.js`, `data.js`,
`sw.js` and the icons. The exceptions are listed below.

## chars.js — Make Me a Hanzi, LGPL v3

`chars.js` holds the character composition data (how each hanzi breaks into components, which
component carries the meaning and which carries the sound, and a short memory aid). It is
generated by `tools/build-chars.js` from the `dictionary.txt` file of
[Make Me a Hanzi](https://github.com/skishore/makemeahanzi), which is itself derived from
[Unihan](https://unicode.org/charts/unihan.html) and [CJKlib](https://github.com/cburgmer/cjklib).

`dictionary.txt` is distributed under the **GNU Lesser General Public License, version 3 or
later**, so `chars.js` is covered by the same license. Full texts are in
[`LICENSES/LGPL-3.0.txt`](LICENSES/LGPL-3.0.txt) and, because the LGPL builds on it,
[`LICENSES/GPL-3.0.txt`](LICENSES/GPL-3.0.txt).

The LGPL asks that the covered part stay replaceable. It does, in the most literal way possible:
`chars.js` is a standalone file loaded with its own `<script src="chars.js">` tag and defines two
plain objects (`CHARS` and `COMPONENTS`). Swap the file, reload the page, and the app uses your
version instead. `tools/build-chars.js` regenerates it from source if you want to rebuild rather
than replace.

Nothing else in this repository is derived from `dictionary.txt`, and the rest of the app's code
is not covered by the LGPL.

## Stroke order animations — hanzi-writer, loaded at runtime

The stroke-order animations and the handwriting check in Write mode use
[HanziWriter](https://hanziwriter.org) (MIT) with the `hanzi-writer-data` character data, both
fetched from a CDN at runtime. Neither is redistributed in this repository. That character data
comes from Make Me a Hanzi's `graphics.txt`, which is published under the
[Arphic Public License](https://www.freedesktop.org/wiki/Arphic_Public_License/), a separate and
more permissive license than the one covering `dictionary.txt`.

## Word lists

The HSK word lists follow the official HSK vocabulary; `ES1`/`ES2` follow the *Easy Steps to
Chinese* textbooks. Definitions, topics and parts of speech in `data.js` were assembled for this
app.
